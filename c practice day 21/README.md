# Day 21 - Preprocessors in C (Theory)

## Introduction

Today I focused on understanding one of the most important concepts in C Programming and Embedded Systems: **The C Preprocessor**.

Unlike normal C statements, preprocessor directives are executed before the actual compilation process begins. They help in code organization, configuration management, portability, debugging, and memory optimization.

Almost every professional Embedded C project uses preprocessors extensively for hardware abstraction, feature control, debugging, and maintaining large codebases.

Study Time: **1 Hour 35 Minutes**

# What is a Preprocessor?

The C Preprocessor is a program that processes source code before the compiler starts compiling it.

It handles directives beginning with the '#' symbol.

Examples:

```c
#include <stdio.h>
#define MAX 100
#ifdef DEBUG
```

The output generated by the preprocessor is then sent to the compiler.

# Header Files

Header files contain declarations and macro definitions that can be shared among multiple source files.

Examples:

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include "myheader.h"
```

### Types of Header Files

#### System Header Files

```c
#include <stdio.h>
```

Provided by the compiler.

#### User Defined Header Files

```c
#include "config.h"
```

Created by programmers.

---

# #include Directive

The #include directive inserts the contents of a file into another source file before compilation.

Benefits:

- Code Reusability
- Better Organization
- Easier Maintenance
- Modular Programming

---

# Macros

Macros are symbolic names replaced by values or code fragments during preprocessing.

### Object-like Macro

```c
#define PI 3.14159
#define MAX_SIZE 100
```

### Function-like Macro

```c
#define SQUARE(x) ((x)*(x))
#define MAX(a,b) ((a)>(b)?(a):(b))
```

Benefits:

- Faster execution
- No function call overhead
- Improved readability

---

# Macro Expansion

During preprocessing:

```c
#define VALUE 10

int a = VALUE;
```

becomes

```c
int a = 10;
```

before compilation.

This process is known as Macro Expansion.

---

# Conditional Compilation

Conditional compilation allows certain sections of code to be included or excluded based on conditions.

### #if

```c
#if VERSION == 1
printf("Version 1");
#endif
```

### #ifdef

```c
#ifdef DEBUG
printf("Debug Mode");
#endif
```

### #ifndef

```c
#ifndef CONFIG_H
```

### #else

```c
#ifdef DEBUG
printf("Debug");
#else
printf("Release");
#endif
```

### #elif

```c
#if MODE == 1
#elif MODE == 2
#endif
```

Applications:

- Debug Builds
- Release Builds
- Platform Specific Code
- Feature Selection

---

# #undef Directive

Used to remove a previously defined macro.

Example:

```c
#define MAX 100
#undef MAX
```

After undefining, the macro no longer exists.

---

# Predefined Macros

The compiler automatically provides several useful macros.

### __FILE__

Displays current file name.

```c
printf("%s", __FILE__);
```

### __LINE__

Displays current line number.

```c
printf("%d", __LINE__);
```

### __DATE__

Compilation date.

```c
printf("%s", __DATE__);
```

### __TIME__

Compilation time.

```c
printf("%s", __TIME__);
```

These are useful for debugging and logging.

---

# Include Guards

Include guards prevent multiple inclusion of the same header file.

Example:

```c
#ifndef MY_HEADER_H
#define MY_HEADER_H

// declarations

#endif
```

Advantages:

- Prevents Compilation Errors
- Reduces Redundant Processing
- Improves Build Stability

# Applications in Embedded Systems

Preprocessors are extensively used in Embedded C development.

### Hardware Configuration

```

### Debugging

### Feature Enable/Disable

```

### Memory Optimization

Compile only required modules.

### Cross Platform Development

Different code for different microcontrollers.

### Register Definitions

```c
#define PORTA (*(volatile unsigned int*)0x40020000)
```
