# Day 16 - Pointers in C (Theory)

## Overview
Today I focused entirely on understanding the theoretical foundations of Pointers in C, one of the most important concepts in Embedded Systems programming.

## Topics Covered

- What is a Pointer?
- Address Operator (&)
- Dereference Operator (*)
- Pointer Declaration and Initialization
- NULL Pointers
- Program Memory Layout
- Pointer Size
- Pointer Arithmetic
- Arrays and Pointers
- Pass by Value vs Pass by Reference
- Void Pointers
- Const with Pointers
- Volatile Pointers
- Memory-Mapped Registers
- Function Pointers
- Applications of Pointers in Embedded Systems

## Why Pointers Matter in Embedded Systems

Pointers are essential for:

- Memory-Mapped Register Access
- Device Driver Development
- Interrupt Handling
- RTOS Kernels
- DMA Operations
- Hardware Interfacing
- Efficient Memory Management

Pointers bridge the gap between software and hardware. Understanding pointers is fundamental to becoming a strong Embedded Systems Engineer.
